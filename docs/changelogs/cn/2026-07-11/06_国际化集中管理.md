# 国际化集中管理

## 更新概述

翻译 key 从散落代码各处的裸字符串升级为集中注册表。新增 `translation_keys.py` 提供 IDE 自动补全、一致性验证和重构安全，同时补全英文翻译中缺失的渲染设置映射。

## 核心改动

### 1. 翻译 Key 集中注册表

**问题**：46 个文件中 434 处 `t("k_xxx")` 调用全部使用裸字符串，无法自动补全、容易拼写错误、重构不安全、无法验证一致性。

**方案**：创建 `ui/core/translation_keys.py`，将 [strings_cn.json](file:///f:/Bionic Neural Network Program Operating System/ui/core/strings_cn.json) 中的所有 270+ 翻译 key 映射为 Python 类属性，JSON 文件仍然是唯一数据源。

修改 / 新增：

- **`ui/core/translation_keys.py`**（新增）：
  - `TranslationKeys` 类：270+ 个 key 以类属性形式暴露，按功能模块分组（项目、节点、画布、组、菜单、设置等）
  - `TK = TranslationKeys` 模块级便捷别名
  - `all_keys()` — 返回所有 key 值列表
  - `count()` — 返回 key 总数
  - `validate()` — 验证 TK 中定义的 key 与 JSON 文件是否一致
  - `list_unused(source_dir)` — 扫描代码目录，找出 JSON 中存在但未使用的 key
  - 属性命名规则：`"k_project_new"` → `PROJECT_NEW`，`"_k_about_text"` → `_ABOUT_TEXT`

- **`ui/core/i18n.py`**（修改）：
  - 新增 `validate_all_keys()` — 启动时一次性验证 TK 注册表与 JSON 的一致性

### 2. 补全英文渲染设置翻译

**问题**：设置 → 渲染 标签页的 8 个翻译 key 只存在于中文 JSON，英文 JSON 缺失，切换英文后这些文本显示 key 名称本身。

**方案**：补全 [strings_en.json](file:///f:/Bionic Neural Network Program Operating System/ui/core/strings_en.json)。

新增翻译：

| Key | 英文 |
|------|------|
| `_k_settings_tab_rendering` | Rendering |
| `_k_settings_rendering_canvas_size` | Canvas Resolution |
| `_k_settings_rendering_preset` | Preset: |
| `_k_settings_rendering_custom` | Custom |
| `_k_settings_rendering_width` | Width: |
| `_k_settings_rendering_height` | Height: |
| `_k_settings_rendering_antialiasing` | Enable Antialiasing |
| `_k_settings_rendering_hint` | Canvas resolution determines the maximum area... |

## 使用方式

```python
# 旧（仍兼容）
t("k_project_new")

# 新（IDE 自动补全、重构安全）
from ui.core.translation_keys import TK
t(TK.PROJECT_NEW)
```
