# 复合节点系统

## 更新概述

实现了"复合节点"功能，支持将画布上多个节点压缩为一个虚拟节点，统一编排运行，支持解耦还原。解决了 BNOS 长时间"只能单层编排、无法抽象子流程"的核心痛点。

## 核心改动

### 1. 复合节点核心逻辑

新增 `ui/core/composite_node.py`（~600行），实现：

- **压缩（compress）**：将多个节点名 → 拓扑排序 → DAG 推导端口 → 生成 orchestrator 脚本 → 写入 `node_clusters.json`
- **解耦（decompress）**：还原原始节点 + 删除节点组 + 清理 PID 文件
- **运行（run/start_inprocess）**：根据 DAG 顺序动态 `importlib.import_module` 各节点 main.py，`process(inputs)` 链式执行
- **run_id / timestamp**：每次运行生成唯一 ID 和时间戳，输出到 `output.json`
- **节点组自动创建**：压缩时自动在 NodeGroupManager 创建同名组并锁定

### 2. 画布渲染

新增 `ui/canvas/items/composite_node_item.py`（~190行）：

- 虚线青绿色边框与通用节点区分
- ⊞ 图标标识（`font-size: 14px`）
- 复合节点标题显示
- 右键菜单：解耦 / 启动 / 停止 / 切换运行时模式
- 拖拽时实时持久化位置到 `node_clusters.json`

### 3. 画布右键菜单

修改 `ui/canvas/mixins/canvas_menus.py`：

- 多选右键菜单新增"⊞ 压缩为复合节点"选项（显示节点数）
- 复合节点专用右键菜单（解耦确认对话框 / 启动 / 停止 / 运行时模式切换）

### 4. Action 注册

新增 `ui/core/actions/node/composite_actions.py`：

- `canvas.compress_to_composite` — 压缩选中的节点
- `canvas.decompress_composite` — 解耦复合节点

### 5. 节点列表集成

修改 `ui/panels/node_list_dock.py` 和 `ui/panels/node_list_context.py`：

- 复合节点组在列表中显示 ⊞ 图标 + 青绿色高亮 + 🔒 锁定标记
- 复合节点组专用右键菜单（解耦 / 启动 / 停止），无 rename/delete 选项

### 6. 项目加载/保存集成

修改 `ui/canvas/canvas_view.py`：

- `restore_composites()` — 项目打开时从 `node_clusters.json` 重建所有复合节点
- 画布序列化兼容 `CompositeNodeItem`

修改 `ui/canvas_widget.py`：
- 新增 `CompositeNodeItem` 导出
