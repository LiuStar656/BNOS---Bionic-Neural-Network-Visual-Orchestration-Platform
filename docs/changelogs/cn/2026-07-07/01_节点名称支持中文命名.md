# 节点名称支持中文命名

## 概述

节点名称现在支持中文及其他语言字符，用户可以用更直观的中文名称命名节点文件夹。

## 问题分析

之前节点名称验证使用正则 `^[a-zA-Z0-9_-]+$`，只允许字母、数字、下划线和连字符，直接阻止了中文命名。

经过分析，节点名称实际上等价于文件夹名称，所有操作最终都落到文件路径上。现代 Windows 文件系统完全支持中文路径，JSON 配置使用 UTF-8 编码也完全支持中文，Qt UI 同样支持中文渲染。因此，只需要修改名称验证规则即可支持中文。

## 解决方案

### 验证规则变更

**旧规则**：`^[a-zA-Z0-9_-]+$` — 仅允许字母、数字、下划线、连字符

**新规则**：`^[^\\/:*?"<>|]+$` — 排除 Windows 文件系统保留字符

### 支持的字符

- ✅ 中文及其他 Unicode 字符（如日文、韩文、特殊符号等）
- ✅ 英文、数字、下划线、连字符、空格
- ❌ 禁止：`\ / : * ? " < > |`（Windows 文件系统保留字符）
- 长度限制：64 个字符

### 统一验证架构

之前存在三处独立的名称验证逻辑，容易导致不一致：
1. `node_list_panel.py` — 重命名验证
2. `node_creator_manager.py` — 创建验证
3. `validators.py` — 通用验证器

现在统一使用 `NodeNameValidator` 进行验证，确保所有入口的规则一致。

## 修改文件

### 核心验证逻辑

| 文件 | 变更内容 |
|------|----------|
| `ui/core/validators.py` | 更新 `ALLOWED_CHARS` 正则为 `^[^\\/:*?"<>|]+$`，移除冗余检查 |

### 验证入口统一

| 文件 | 变更内容 |
|------|----------|
| `ui/panels/node_list_panel.py` | 重命名功能改用 `NodeNameValidator.validate()` |
| `ui/creators/node_creator_manager.py` | 创建功能改用 `NodeNameValidator.validate()`，移除重复的空值检查 |

### 国际化文本

| 文件 | 变更内容 |
|------|----------|
| `ui/core/strings_cn.json` | 更新错误提示："节点名称只能包含字母、数字、下划线和连字符" → "节点名称不能包含特殊字符: \\ / : * ? \" < > \|" |
| `ui/core/strings_en.json` | 更新错误提示："Node name can only contain letters, numbers, underscores and hyphens" → "Node name cannot contain special characters: \\ / : * ? \" < > \|" |

## 兼容性

- **Windows**：完全支持中文路径和文件名
- **Linux/Mac**：中文路径支持取决于系统语言环境
- **JSON 配置**：使用 UTF-8 编码，完全支持中文
- **Qt UI**：完全支持中文渲染

## 注意事项

1. 中文节点名称在 Linux/Mac 环境下可能需要确保系统语言环境正确配置
2. 节点名称会直接作为文件夹名称，因此禁止使用文件系统保留字符
3. 建议避免使用过长的节点名称（限制 64 字符）
