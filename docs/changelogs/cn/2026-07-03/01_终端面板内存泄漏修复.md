# 终端面板内存泄漏修复

## 问题描述

用户怀疑终端面板关闭时终端进程没有被停止，导致 `powershell.exe` 进程在后台持续运行，造成内存泄漏。

## 根因分析

通过代码追踪发现了三条导致终端进程泄漏的路径：

### 路径 1：面板隐藏时不触发 `closeEvent`

`toggle_terminal()` 使用 `hide()`/`show()` 切换可见性，不会触发 `closeEvent`，因此 `TerminalDock.closeEvent()` 中的 `stop_all_terminals()` 从未执行。

```python
def toggle_terminal(self):
    if self._terminal_dock.isVisible():
        self._terminal_dock.hide()  # 不会触发 closeEvent
    else:
        self._terminal_dock.show()
```

### 路径 2：`_remove_dock()` 绕过 `closeEvent`

`_remove_dock()` 直接调用 `deleteLater()`，绕过了 `closeEvent`，导致终端进程在面板关闭时未被清理。

```python
def _remove_dock(self, dock, edge):
    self._main_window.removeDockWidget(dock)
    dock.deleteLater()  # 不会触发 closeEvent
```

### 路径 3：清理逻辑不处理 `QProcess`

`_stop_content_timers()` 只清理 `QTimer` 和 `QThread`，**不处理 `QProcess`**。而且 `TerminalProcess` 是 `QObject` 嵌套 `QProcess`，`findChildren` 默认无法找到嵌套的 `QProcess` 对象。

## 修复方案

在 `_stop_content_timers()` 中添加两层防护：

### 1. `QProcess` 清理

遍历所有 `QProcess` 子对象，执行三级终止链：
- `terminate()`：温和终止
- `kill()`：强制杀死（3秒超时后）
- `taskkill /F /T`：系统级兜底（再超时后）

### 2. `TerminalWidget` 显式清理

导入并调用 `TerminalWidget.close_terminal()`，确保嵌套的 `TerminalProcess` 也被正确停止。
