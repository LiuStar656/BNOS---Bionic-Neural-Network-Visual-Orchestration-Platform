# 09 复合节点健壮性增强

## 概述

针对复合节点系统的 4 个设计缺陷进行增强：拖拽性能、磁盘异常防护、配置冲突校验、编排器断点续跑，以及预埋分布式传输接口。

---

## 一、P0 — 拖拽 20+ 节点卡顿

**根因**：`canvas_event_handlers.py` 的 `_sync_composite_group_movement` 每帧写回 anchor 字典，触发 N 次画布重绘。

**修复**：去掉逐帧写回，`mouseRelease` 时**批量持久化**位置。

| 文件 | 改动 |
|------|------|
| `canvas_event_handlers.py` | 移除 anchor 逐帧更新，`mouseRelease` 批量写回 |

---

## 二、P0 — orchestrator / 日志写入磁盘异常

**根因**：`open(log_file, "w")` 和 `open(orchestrator_path, "w")` 无 `PermissionError` / `OSError` 分支。

**修复**：3 处 try/except + themed_message 友好弹窗。

| 文件 | 改动 |
|------|------|
| `composite_node.py` | `start_inprocess()` 文件打开加 `PermissionError/OSError` 保护 |
| `composite_orchestrator.py` | 编排器脚本写入加异常保护 |

---

## 三、P1 — config 外部修改冲突校验

**场景**：展开复合节点 → 在画布上修改内部节点 config → 折叠 → 外部修改被静默覆盖。

**修复**：展开时快照 `_config_snapshot` → 折叠时对比 → 日志警告。

| 文件 | 改动 |
|------|------|
| `composite_node.py` | `_decompress()` 展开时快照，`_compress()` 折叠时对比 |

---

## 四、P1 — 编排器断点续跑

**场景**：内部 DAG 某节点报错后需整体重启，已成功的节点白跑了。

**修复**：`_try_read_cache()` 检查子节点 `output.json` → 已完成节点跳过。

| 文件 | 改动 |
|------|------|
| `composite_orchestrator.py` | `_try_read_cache` + `execute()` 跳过逻辑 |

---

## 五、P2 — 分布式传输接口（预埋）

为未来多机编排预留抽象接口，不影响现有单机逻辑：

| 文件 | 改动 |
|------|------|
| `transports/__init__.py` | 新建 `TransportHandler` ABC（`send` / `receive` / `ping`） |
| `composite_node.py` | `execute()` → `_execute_local()` 分发 |

总改动：~200 行，7 文件修改 + 1 新建。
