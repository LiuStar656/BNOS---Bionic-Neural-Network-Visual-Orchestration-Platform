# 02 代码规范统一化整改

## 概述

对 BNOS 全项目（227 个 Python 文件）实施代码规范统一化整改，建立自动化质量门禁体系，消除历史遗留的风格不一致和真实 Bug。

---

## 一、工具链引入（从零搭建）

| 工具 | 配置 | 作用 |
|------|------|------|
| **Ruff** | `pyproject.toml` | 替代 flake8 + black + isort，200+ 规则自动检查与修复 |
| **Pre-commit** | `.pre-commit-config.yaml` | `git commit` 时自动执行 ruff check + format |
| **EditorConfig** | `.editorconfig` | 统一缩进(4空格)、换行符(LF)、UTF-8 编码 |
| **Pylance** | `pyrightconfig.json` | IDE 实时类型检查，精准压制 Mixin/Qt 误报 |

---

## 二、消除真实 Bug（8 个）

规范化检测中发现的**会导致运行时崩溃或逻辑错误**的问题：

| 文件 | Bug | 后果 |
|------|-----|------|
| `ui/core/actions/composite_actions.py` | `execute_fn=decompress` 引用未定义变量 | `NameError` 崩溃 |
| `ui/core/node/external_node_manager.py` | 2 处 `except Exception:` 内 lambda 引用未捕获的 `e` | 异常处理中二次崩溃 |
| `ui/core/system/ipc.py` | 3 处闭包循环变量捕获 | 所有回调使用最后一个循环值 |
| `ui/main_window/state.py` | `_restore_terminal_dock` 重复定义 | 第一个实现为死代码 |
| `ui/core/utils/changelog_viewer.py` | 缺少 `logger` 导入 | `NameError` |
| `ui/panels/performance_panel.py` | 缺少 `polling_manager` 导入 | `ImportError` |
| `ui/canvas/mixins/canvas_node_manager.py` | `NodeConfigDialog` 导入路径错误 | `ImportError` |
| `ui/panels/node_list_ops.py` / `node_expand_panel.py` | 同上（3 处） | `ImportError` |

## 四、Python 3.12 现代化

### `from __future__ import annotations` 全局覆盖

- **219 个文件**新增，覆盖全项目
- 支持 `str | None` 替代 `Optional[str]` 语法

### `# type: ignore` 清零

- `ui/core/actions/action_registry.py`：8 处 → **0 处**
- `pyrightconfig.json` 新增 5 项精准压制（`reportAttributeAccessIssue` 等），针对 Mixin 模式误报

### os.path → pathlib.Path

| 阶段 | os.path 数量 | 影响文件 |
|------|-------------|----------|
| 整改前 | 691 处 | 72 文件 |
| 整改后 | 156 处 | 42 文件 |
| **降幅** | **-77%** | |

转换范围覆盖：核心工具模块（`dialog_utils.py`、`packager.py`、`file_utils.py`、`polling_manager.py`）、节点系统（`node_process.py`、`composite_node.py`、`ide_scanner.py` 等）、项目管理、画布混入、对话框面板、入口文件等 **25+ 个文件**。
