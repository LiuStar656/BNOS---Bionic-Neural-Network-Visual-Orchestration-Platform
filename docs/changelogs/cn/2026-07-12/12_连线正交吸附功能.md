# 12 连线正交吸附功能

## 概述

新增连线直角吸附功能：拖拽连线折叠点时，自动吸附到最近的直角交点，使线段变为水平或垂直方向。支持菜单开关和 Shift 临时禁用。

---

## 一、交互方式

| 操作 | 效果 |
|------|------|
| 拖拽折叠点 | **自动吸附**到最近的直角交点 |
| 按住 Shift + 拖拽 | 临时禁用吸附，恢复自由拖拽 |
| 右键画布 → 正交吸附: 开/关 | 全局切换吸附功能 |

---

## 二、吸附算法

```
拖拽折叠点 wp，前后相邻点为 prev 和 next：

候选 1: (prev.x, next.y)  →  prev→wp 垂直，wp→next 水平
候选 2: (next.x, prev.y)  →  prev→wp 水平，wp→next 垂直

选择最接近鼠标的候选。距离超过 20px 时不吸附（保留自由拖拽）。
```

三维空间效果（画布上拖拽时）：

```
┌───────┐     → 自由拖拽（无吸附）
│  A    │
│       │───┐
└───────┘   │
            │  ← 拖拽至此自动吸附
┌───────┐   │
│  B    │───┘
└───────┘
```
