# 09 复合节点防错窗口风格统一

## 概述

复合节点相关的 6 处 QMessageBox 替换为 `themed_message()`，统一对话框风格。解决原生 Windows 白色对话框在深色主题 BNOS 中的视觉割裂问题。

---

## 一、问题

复合节点的确认/错误弹窗直接调用 `QMessageBox.question()` / `QMessageBox.warning()`，弹出 Windows 原生白色系统对话框，与 BNOS 的深色圆角无边框风格严重不协调。

---

## 二、修改清单

| 文件 | 位置 | 修改前 | 修改后 |
|------|------|--------|--------|
| `composite_node_item.py` | `_decompress` 确认 | `QMessageBox.question(...)` | `themed_message(..., "question")` |
| 同上 | `_decompress` 失败 | `QMessageBox.warning(...)` | `themed_message(..., "error")` |
| 同上 | `_start` 失败 | `QMessageBox.warning(...)` | `themed_message(..., "error")` |
| `composite_node.py` | 折叠阻断 | `QMessageBox.warning(...)` | `themed_message(..., "warning")` |
| 同上 | 环境创建失败 | `QMessageBox.warning(...)` | `themed_message(..., "error")` |
| `canvas_menus.py` | 启动失败 | `QMessageBox.warning(...)` | `themed_message(..., "error")` |

---

## 三、效果对比

```
修改前 (QMessageBox):          修改后 (themed_message):
┌─────────────────────┐        ┌───────────────────────┐
│  ❌ (Windows 原生)   │        │  确认解耦              │
│  Restore to 3...?   │        │  将复合节点还原为...   │
│  [Yes]  [No]        │        │  [否]    [是]         │
│  ← 白色系统风格 →    │        │  ← 深色/圆角/半透明 →  │
└─────────────────────┘        └───────────────────────┘
```

同时复用了已有的 i18n 标准键（`k_title_error`、`k_composite_decompress_confirm_title` 等），确保中文/英文模式一致。
