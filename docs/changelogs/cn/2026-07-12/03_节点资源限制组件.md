# 03 节点资源限制组件

## 概述

为 BNOS 新增全平台节点资源限制能力。用户可在节点的 `config.json` 中声明 `resource_limit` 字段，限制该节点进程的 CPU 占用和内存使用。底层根据操作系统自动选择最佳实现：Linux cgroups v2、Windows Job Objects、macOS nice 优先级。

## 架构设计

### 类继承体系

```
ResourceLimit (ABC)                           ← 抽象基类：优先级 + 亲和性 + 硬限制接口
├── _LinuxResourceLimit                       ← cgroups v2: cpu.max + memory.max
├── _WindowsResourceLimit                     ← Job Objects: CPU Rate Control + ProcessMemoryLimit
└── _DarwinResourceLimit                      ← macOS: 仅优先级（硬限制不支持）
```

### 工厂函数

```python
from ui.core.system.resource_limit import create_resource_limit

limit = create_resource_limit(pid, config["resource_limit"])
applied = limit.apply()
# → ["priority=below_normal", "memory_mb=4096", "cpu_percent=200"]
```

### config.json 字段

| 字段 | 类型 | 说明 | Linux | Windows | macOS |
|------|------|------|:---:|:---:|:---:|
| `priority` | `string` | 进程优先级 | nice | PriorityClass | nice |
| `cpu_affinity` | `list[int]` | 绑定 CPU 核心 | ✅ | ✅ | 忽略 |
| `cpu_percent` | `int` | CPU 上限（100=1 核） | cgroups | JobObject | 忽略 |
| `memory_mb` | `int` | 内存硬上限（MB） | cgroups | JobObject | 忽略 |

### priority 映射

| 值 | Linux (nice) | Windows (PriorityClass) |
|----|-------------|------------------------|
| `"low"` | 19 | IDLE |
| `"below_normal"` | 10 | BELOW_NORMAL |
| `"normal"` | 0 | NORMAL |
| `"above_normal"` | -5 | ABOVE_NORMAL |
| `"high"` | -10 | HIGH |

## 关键设计决策

### 延迟进程获取

`ResourceLimit.__init__` 不再在构造阶段获取 `psutil.Process`，改为延迟到 `apply()` 阶段。PID 不存在时静默降级而非抛异常。

### 全平台静默降级

- macOS 不支持硬 CPU/内存限制 → 仅记录日志，不影响节点启动
- Windows/Linux 无管理员/root 权限时 → 记录警告，不阻断流水线
- CPU 亲和性在 macOS 上被忽略

### 上下文管理器支持

```python
with create_resource_limit(pid, config) as limit:
    limit.apply()
    # 退出时自动清理（当前无需显式清理，但预留接口）
```
