# 参数定义与锚点管理代码清理

## 更新概述

本次更新修复了参数定义的兼容性问题，并清理了锚点管理器中的死代码。

## 核心改动

### 1. ParameterDef 添加 description 字段

修改 `ui/core/node_config_parser.py`：

- 在 `ParameterDef` 数据类中添加 `description` 字段
- 解析时过滤未知字段，防止 TypeError
- 支持参数描述信息的存储和传递

### 2. AnchorManager 死代码移除

修改 `ui/canvas/items/anchor_manager.py`：

- 移除未使用的方法：`layout_for_rect`、`layout_for_dot`、`_layout_default_input`、`_layout_default_output`
- 清理未使用的导入和变量
- 简化代码结构，提高可维护性

### 3. 代码健壮性提升

- 添加类型注解和文档字符串
- 统一错误处理方式
- 优化代码可读性

## 文件变更

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `ui/core/node_config_parser.py` | 修改 | 添加 description 字段支持 |
| `ui/canvas/items/anchor_manager.py` | 修改 | 移除死代码 |
