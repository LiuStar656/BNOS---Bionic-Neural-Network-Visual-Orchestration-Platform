# 节点启动机制改进与自定义入口脚本支持

## 更新概述

本次更新完善了节点启动机制，支持在 `start.json` 中配置自定义启动程序，并同步更新了节点开发工具。

## 核心改动

### 1. start.json 新增 entry 字段

在 `start.json` 中新增 `entry` 字段，允许用户指定自定义启动脚本路径：

```json
{
  "entry": "main.py",
  "venv_path": "venv"
}
```

- `entry` 字段可选，默认为 `main.py`
- 支持相对路径和绝对路径
- 向后兼容：不设置时使用默认值

### 2. 节点启动流程优化

修改 `ui/core/node_process.py` 中的启动逻辑：

- 优先读取 `start.json` 中的 `entry` 字段
- 不存在时回退到默认 `main.py`
- 支持启动其他程序（如脚本、可执行文件等）

### 3. 节点开发工具更新

更新 `tools/python_create_node.py`：

- 创建节点时提示用户输入自定义入口文件
- 默认值为 `main.py`，保持向后兼容
- 更新节点开发规范文档，说明 `start.json` 的配置方式

### 4. 开发规范更新

更新 `tools/节点开发规范.md` 和 `tools/config_json_开发规范.md`：

- 添加 `start.json` 的完整配置说明
- 说明 `entry` 字段的使用方法和默认值
- 提供自定义启动程序的配置示例

## 文件变更

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `ui/core/node_process.py` | 修改 | 支持读取 start.json 的 entry 字段 |
| `tools/python_create_node.py` | 修改 | 支持自定义入口文件输入 |
| `tools/节点开发规范.md` | 修改 | 添加 start.json 配置说明 |
| `tools/config_json_开发规范.md` | 修改 | 添加 entry 字段说明 |
