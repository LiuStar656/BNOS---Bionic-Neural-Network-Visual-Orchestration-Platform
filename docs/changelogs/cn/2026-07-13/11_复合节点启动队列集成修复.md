# 复合节点启动队列集成修复

## 问题描述

复合节点启动存在以下问题：
- 右键菜单启动复合节点时没有经过启动队列
- 启动时没有显示启动提示 toast
- 启动后状态没有更新（节点列表组颜色、画布节点状态）

## 根本原因

`_composite_start` 和 `_start_composite_group` 方法直接调用了 `mgr.start_inprocess()`，没有经过启动队列，因此没有启动提示和状态更新。

## 修复方案

### 修改的文件

**1. ui/canvas/mixins/canvas_menus.py**

`_composite_start` 方法改为通过启动队列启动：
```python
startup_queue.enqueue(comp_id)
# 获取主窗口并显示启动提示
app = QApplication.instance()
main_window = app.activeWindow()
main_window.show_toast(t("_k_node_starting").format(name=comp_id), "info")
```

**2. ui/panels/node_list_context.py**

`_start_composite_group` 方法改为通过启动队列启动

**3. ui/main_window/node.py**

更新事件处理函数，添加 `_update_composite_status` 方法处理复合节点状态更新：
- 更新节点列表组颜色（starting → running）
- 更新画布节点状态样式

**4. ui/canvas/items/composite_node_item.py**

添加 `update_status` 方法，用于更新复合节点的运行状态显示

**5. ui/main_window/node.py**

修改 `start_selected_node_by_name` 和 `stop_selected_node_by_name`，让它们能处理复合节点：
- 启动：通过启动队列启动
- 停止：通过 `composite_manager.stop_composite` 停止

## 修复后的行为

- ✅ 复合节点启动时加入启动队列
- ✅ 显示启动提示 toast
- ✅ 更新节点列表组颜色
- ✅ 更新画布节点状态样式
- ✅ 启动/停止动作可以作用到复合节点
