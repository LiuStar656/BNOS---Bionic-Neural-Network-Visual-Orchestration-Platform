# 06 复合节点启动队列集成

## 问题描述

复合节点启动时没有经过启动队列，导致：
1. 没有启动提示（toast）
2. 状态不会更新
3. 无法享受启动队列的并发控制、重试机制等功能

## 修复方案

### 6.1 NodeStartWorker 自动判断节点类型

**文件**：`ui/core/node/node_startup_queue.py`

`NodeStartWorker.run()` 根据节点名前缀 `composite_` 自动选择启动方式。

**代码变更**：
```python
def run(self):
    node_name = self._item.node_name
    if node_name.startswith("composite_"):
        self._start_composite(node_name)
    else:
        self._start_regular_node(node_name)
```

### 6.2 新增复合节点启动方法

**文件**：`ui/core/node/node_startup_queue.py`

新增 `_start_composite()` 方法，通过 `CompositeNodeManager` 启动复合节点。

**代码变更**：
```python
def _start_composite(self, comp_id: str):
    from ui.core.node.composite_node import CompositeNode
    ...
    mgr = getattr(main_window.canvas, "_composite_manager", None)
    runtime = mgr.get_runtime(comp_id) or "inprocess"
    if runtime == "inprocess":
        success, err = mgr.start_inprocess(comp_id)
    else:
        success, err = mgr.start_process_mode(comp_id)
    self.finished.emit(success, err)
```

### 6.3 右键菜单启动改为通过队列

**文件**：`ui/canvas/mixins/canvas_menus.py`

`_composite_start()` 改为调用 `startup_queue.enqueue()`。

**代码变更**：
```python
def _composite_start(self, mgr, comp_id):
    from ui.core.node.node_startup_queue import startup_queue
    startup_queue.enqueue(comp_id)
    self.show_toast(t("_k_node_starting").format(name=comp_id), "info")
```

### 6.4 节点列表启动改为通过队列

**文件**：`ui/panels/node_list_context.py`

`_start_composite_group()` 改为调用 `startup_queue.enqueue()`。

### 6.5 主窗口事件处理支持复合节点

**文件**：`ui/main_window/node.py`

更新 `_on_queue_node_starting`、`_on_queue_node_started`、`_on_queue_node_failed`，添加 `_update_composite_status()` 方法处理复合节点状态更新。

### 6.6 CompositeNodeItem 添加 update_status 方法

**文件**：`ui/canvas/items/composite_node_item.py`

添加 `update_status()` 方法，更新状态并应用样式。

**代码变更**：
```python
def update_status(self, status):
    self.status = status
    if hasattr(self, '_style'):
        self._style.apply_status(self, status)
```
