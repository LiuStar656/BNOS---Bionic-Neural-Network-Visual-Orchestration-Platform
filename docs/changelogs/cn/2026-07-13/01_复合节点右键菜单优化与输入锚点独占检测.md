## 一、复合节点右键菜单优化

### 背景

右键菜单存在三个问题：
1. "启动复合节点"和"停止复合节点"同时显示，用户可能误操作
2. "解耦为独立节点"在菜单最顶层，不符合操作频率和风险等级
3. 展开/折叠和解耦操作未检测运行状态，运行中操作可能导致数据异常

### 修改内容

#### 文件：`ui/canvas/mixins/canvas_menus.py`

**1. 启动/停止互斥显示**

在 `_show_composite_node_menu` 入口处获取 `mgr.is_running(comp_id)`，根据运行状态只显示"启动"或"停止"中的一个：

```python
is_running = mgr.is_running(comp_id)
if is_running:
    stop_action = menu.addAction("停止复合节点")
else:
    start_action = menu.addAction("启动复合节点")
```

**2. 解耦移至最底层 + 运行状态检测**

解耦操作移到菜单最底部，运行时灰显（`setEnabled(False)`）并显示 tooltip：

```python
decompress_action = menu.addAction("解耦为独立节点")
if is_running:
    decompress_action.setEnabled(False)
    decompress_action.setToolTip("复合节点运行中，请先停止")
```

**3. 展开/折叠运行状态检测**

展开/折叠按钮运行时灰显 + tooltip，同时新增 `_on_toggle_expand` 方法做双重弹窗校验（防止从其他入口绕过菜单）：

```python
def _on_toggle_expand(self, mgr, comp_id):
    if mgr.is_running(comp_id):
        themed_message(None, "警告", "复合节点正在运行中，请先停止后再展开/折叠", "warning")
        return
    mgr.toggle_expand(comp_id)
```

**4. 菜单最终结构**

从上到下：
1. 启动复合节点 / 停止复合节点（互斥）
2. ———— 分隔线 ————
3. 展开 / 折叠（运行时灰显）
4. ———— 分隔线 ————
5. 运行时模式子菜单（独立进程 / 单进程）
6. ———— 分隔线 ————
7. 解耦为独立节点（运行时灰显）

## 二、输入锚点独占检测

### 背景

系统连接规则：一个输出锚点 → 多个输入锚点（已实现），但缺少"一个输入锚点只能接受一条连线"的限制。如果不限制，多个上游节点同时向同一输入端写入会引发数据竞争。

### 修改内容

#### 文件：`ui/canvas/mixins/canvas_connections.py`

在 `create_edge` 方法中，原有的重复检测之后、EdgeItem 创建之前，新增两段检测：

**1. 指定了具体输入锚点（多端口节点）**

通过 `target_anchor.edges` 检查该锚点是否已有连线：

```python
if target_anchor and hasattr(target_anchor, "port_name"):
    if target_anchor.edges:
        port_label = getattr(target_anchor, "port_label", "") or getattr(target_anchor, "port_name", "")
        themed_message(self.canvas, "连线被拒绝",
                       f"输入端口「{port_label}」已连接，一个输入端口只能接入一条连线。",
                       "warning")
        return
```

**2. 未指定锚点（默认输入端）**

通过 `target_node.input_anchor.edges` 检查默认输入端：

```python
else:
    default_input = getattr(target_node, "input_anchor", None)
    if default_input and default_input.edges:
        themed_message(self.canvas, "连线被拒绝",
                       "该节点的输入端已连接，一个输入端口只能接入一条连线。",
                       "warning")
        return
```

### 不影响范围

- 输出锚点 → 多个输入锚点：继续允许，无变化
- 布局加载（`CanvasLayout.load_layout`）：直接构造 EdgeItem，不经过 `create_edge`，保存的布局可正常恢复
- 原有同源同目标重复检测：保留在独占检测之后
