# 04 节点运行态保护

## 问题描述

对正在运行中的节点执行重命名或删除操作可能导致数据丢失、进程异常或资源泄漏。

## 修复方案

### 4.1 重命名保护

**文件**：`ui/panels/node_list_panel.py`

重命名前检测节点状态，如果节点处于 `running` 或 `starting` 状态，弹出 toast 警告并拒绝操作。

**代码变更**：
```python
from ui.core.node.node_process import check_node_not_running

ok, msg = check_node_not_running(old_name, self.nodes_data)
if not ok:
    if self.parent_window:
        self.parent_window.show_toast(msg, "warning")
    return
```

### 4.2 删除保护

**文件**：`ui/panels/node_list_panel.py`

删除前筛查选中节点中的运行中节点，如果存在，弹出确认对话框提示用户删除将同时停止这些节点。

**代码变更**：
```python
running = [
    n for n in selected_nodes
    if self.nodes_data.get(n, {}).get("status") in ("running", "starting")
]
if running:
    names = "、".join(running)
    reply = themed_message(
        self,
        "确认删除",
        f"以下 {len(running)} 个节点正在运行中：\n{names}\n\n"
        f"删除将同时停止这些节点。是否继续？",
        "warning2",
    )
    if reply != MSG_ACCEPT:
        return
```

### 4.3 通用检测函数

**文件**：`ui/core/node/node_process.py`

新增 `check_node_not_running()` 函数，提供统一的运行态检测逻辑。

**代码变更**：
```python
def check_node_not_running(node_name: str, nodes_data: dict) -> tuple[bool, str]:
    node_info = nodes_data.get(node_name, {})
    status = node_info.get("status", "unknown")
    if status in ("running", "starting"):
        return False, f"节点「{node_name}」正在运行中，请先停止后再操作"
    return True, ""
```

## 效果验证

修复后：
- ✅ 运行中的节点无法重命名，弹出警告提示
- ✅ 删除包含运行中节点时，显示确认对话框列出所有运行中节点
- ✅ 用户可选择继续删除（同时停止节点）或取消操作
