# 08 锚点管理器多输出端口支持

## 问题描述

锚点管理器只支持单个输出锚点，无法渲染 `node_config.json` 中配置的多个自定义输出端口。

## 修复方案

### 8.1 重写输出锚点生成逻辑

**文件**：`ui/canvas/items/anchor_manager.py`

优先使用 `output_ports` 配置的多输出端口，否则回退到单个 default 输出锚点。

**代码变更**：
```python
config_output_ports = {}
for p in NodeConfigParser.parse_output_ports(config):
    config_output_ports[p.name] = p

if config_output_ports:
    port_list = list(config_output_ports.values())
    for port in port_list:
        # 优先使用 row_positions 中的位置，否则垂直分布
        if port.name in positions:
            # 使用配置的位置
        else:
            # 自动计算位置
            header_h = 26
            divider = 4
            top = header_h + divider
            available_h = nh - top - 16
            n = len(port_list)
            idx = port_list.index(port)
            if n == 1:
                out_center_y = top + available_h / 2
            else:
                out_center_y = top + (available_h * idx) / (n - 1)
            out_center_x = nw
            out_size = ANCHOR_SIZE_SMALL
        # 创建锚点
else:
    # 回退到单输出锚点模式
```

## 效果验证

修复后：
- ✅ 支持 `node_config.json` 中配置的多个自定义输出端口
- ✅ 输出端口垂直分布在节点右侧
- ✅ 优先使用 `row_positions` 中配置的位置
- ✅ 无多输出配置时回退到单个 default 输出锚点
