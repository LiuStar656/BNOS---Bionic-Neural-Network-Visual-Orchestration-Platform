# 节点多选功能修复

## 问题描述

之前节点多选存在以下问题：
- Ctrl+单击选中第二个节点时，第一个节点的选中框会马上消失
- 直接 Ctrl+单击选中节点时，选中框也会马上跳出
- 多选数量统计不正确，无法选中超过2个节点

## 根本原因

Qt 的 `QGraphicsScene` 默认选择模式是 `SingleSelection`，当调用 `setSelected(True)` 时会自动取消其他节点的选中状态，导致多选功能失效。

## 修复方案

使用自定义选中标志 `_is_custom_selected` 完全绕过 Qt 的选择模式：

### 修改的文件

**1. ui/canvas/items/node_components/rendering.py**

绘制时检查自定义选中标志：
```python
is_selected = getattr(self._node, '_is_custom_selected', False) or self._node.isSelected()
border_color = QColor("#66b0ff") if is_selected else QColor(body_border)
```

**2. ui/canvas/mixins/canvas_selection.py**

- `on_node_selected`：普通单击时清除所有自定义选中状态，仅选中当前节点
- `_toggle_node_selection`：Ctrl+单击时切换自定义选中状态

**3. ui/canvas/canvas_view.py**

- `SelectedNodesList._sync`：同步自定义选中状态到缓存列表
- `append/remove/clear`：操作自定义选中标志

**4. ui/canvas/drawing/tools/selection_tool.py**

空白点击时清除所有自定义选中状态

## 修复后的选择行为

| 操作 | 行为 |
|------|------|
| 普通单击 | 清除所有选择，选中当前节点 |
| Ctrl+单击 | 切换当前节点的选中状态（支持多选） |
| 空白点击 | 取消所有选择 |
