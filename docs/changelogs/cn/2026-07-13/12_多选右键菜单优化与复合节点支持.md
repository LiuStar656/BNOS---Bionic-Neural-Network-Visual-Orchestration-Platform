# 多选右键菜单优化与复合节点支持

## 问题描述

多选右键菜单存在以下问题：
- 框选或 Ctrl 选中复合节点时，选中数量统计不包含复合节点
- 多选后的右键菜单里启动/停止不包含复合节点
- 选中包含复合节点时仍然显示"压缩为复合节点"和"批量移除"选项

## 修复方案

### 修改的文件

**1. ui/canvas/canvas_view.py**

修改 `SelectedNodesList._sync` 方法，让它也包含复合节点：
```python
from ui.canvas.items.composite_node_item import CompositeNodeItem
# 现在同时检查 NodeItem 和 CompositeNodeItem
if isinstance(item, (NodeItem, CompositeNodeItem))
```

**2. ui/canvas/mixins/canvas_menus.py**

修改 `_show_multi_node_menu` 方法，根据是否包含复合节点动态调整菜单选项：
```python
has_composite = any(n.startswith("composite_") for n in node_list)

if not has_composite:
    # 仅当不包含复合节点时显示：批量移除、压缩为复合节点
```

**3. ui/main_window/node.py**

修改 `start_selected_node_by_name` 和 `stop_selected_node_by_name`，让它们能处理复合节点：
- 启动：通过启动队列启动
- 停止：通过 `composite_manager.stop_composite` 停止

## 修复后的多选右键菜单行为

| 条件 | 显示的选项 |
|------|----------|
| 不包含复合节点 | 启动、停止、批量移除、压缩为复合节点、解耦（如果适用）、清除监听配置、清除选择 |
| 包含复合节点 | 启动、停止、解耦（如果适用）、清除监听配置、清除选择 |

## 新增菜单选项

- 清除选择：用于取消当前所有选中状态
