# 05 复合节点 UI 重构与自定义接口支持

## 问题描述

复合节点 UI 与普通节点不一致，且无法正确渲染自定义端口配置。

## 修复方案

### 5.1 复用普通节点组件

**文件**：`ui/canvas/items/composite_node_item.py`

使用普通节点的组件实现一致的 UI：
- `NodeRendering`：节点渲染
- `AnchorManager`：锚点管理
- `NodeSubComponents`：子组件（状态指示器、选择环、文本标签）
- `NodeParamPanel`：参数面板

**代码变更**：
```python
self._rendering = NodeRendering(self)
self._subcomponents = NodeSubComponents(self)
self._subcomponents.build_status_indicator()
self._subcomponents.build_selection_ring()
self._subcomponents.build_text_labels()
self.anchor_manager = AnchorManager(self)
self._param_panel = NodeParamPanel(self)
```

### 5.2 隐藏冗余元素

隐藏 IN/OUT 标签和展开按钮，保留状态指示器。

### 5.3 过滤系统端口

过滤系统生成的端口（如 `_out` 后缀、`node_` 前缀），只显示用户自定义端口。

**代码变更**：
```python
if port_name.endswith("_out") or port_name.startswith("node_"):
    continue
```

### 5.4 修复缺失属性

显式调用 `build_text_labels()` 创建 `name_text` 属性，解决 `AttributeError: 'CompositeNodeItem' object has no attribute 'name_text'` 错误。

### 5.5 添加复合节点标记

左上角添加绿色圆点标识复合节点。

## 修改文件清单

| 文件 | 改动 |
|------|------|
| `ui/canvas/items/composite_node_item.py` | 重构为复用普通节点组件；隐藏冗余元素；添加绿色圆点标记 |

## 效果验证

修复后：
- ✅ 复合节点 UI 与普通节点一致
- ✅ 自定义输入/输出端口正确渲染
- ✅ 系统端口自动过滤，只显示用户定义的端口
- ✅ 复合节点有绿色圆点标记，便于识别
