# 节点详情面板合并与复合节点配置窗口修复

## 问题描述

### 问题1：复合节点配置窗口为空

打开复合节点配置窗口时，窗口内容为空，没有任何 UI 元素。

**根本原因**：
1. `NodeDetailPanel._init_ui` 方法存在缩进错误，`try` 块只包含了前两行代码，导致大部分 UI 构建代码没有被执行
2. `CompositeNodeProvider` 使用了错误的属性名 `project_path`，而主窗口实际使用的是 `current_project_path`

### 问题2：复合节点重启后无法展开

创建复合节点后可以正常展开，但重启项目后展开时报错：
```
_expand_composite: internal node node_python_2 missing from canvas, removing from composite
_expand_composite: no internal nodes remaining for composite_c811a9f5
```

**根本原因**：`save_layout` 在保存布局时，对于折叠状态的复合节点，其内部子节点被完全跳过不保存到 `canvas_layout.json`，导致重启后无法恢复。

## 修复方案

### 修改的文件

**1. ui/dialogs/node_detail_panel.py**

- 修复 `_init_ui` 方法的缩进错误，将所有 UI 构建代码放入 `try` 块中
- 添加异常捕获和用户提示，当初始化失败时显示错误信息

**2. ui/dialogs/node_data_provider.py**

- 修改 `CompositeNodeProvider.__init__`，使用 `current_project_path` 而非 `project_path`

**3. ui/canvas/mixins/canvas_layout.py**

- 修改 `save_layout`：保存所有节点（包括复合节点内部节点），并添加 `is_internal` 标记
- 修改 `load_layout`：使用布局文件中的 `is_internal` 标记判断节点是否为内部节点，内部节点加载后保持隐藏状态

**4. ui/dialogs/json_sync_editor.py（新增）**

- 实现双向同步的 JSON 编辑器，封装防抖保存和外部变化检测逻辑

**5. ui/dialogs/log_viewer_widget.py（新增）**

- 实现日志查看器，支持日志文件选择、轮询更新和清除功能

**6. ui/dialogs/node_control_widget.py（新增）**

- 实现节点控制组件，包含启动/停止按钮和状态显示
- 添加防错保护：使用 `_operation_in_progress` 标志防止启动/停止按钮并发点击导致信号冲突

**7. ui/canvas/mixins/canvas_node_manager.py**

- 添加 `_remove_from_composite_if_inside` 方法，删除节点时同步更新复合节点内部列表

**8. ui/core/node/composite_node.py**

- 改进 `_expand_composite` 方法，允许部分节点缺失时继续展开并清理无效节点

**9. ui/canvas/mixins/canvas_menus.py**

- 移除普通节点右键菜单中的重复选项"展开节点"，只保留"配置"选项

## 功能改进

### 窗口合并

将"展开节点"窗口和"节点配置"窗口合并为统一的 **节点详情面板**，支持：
- **Config/Output/Logs** 标签页（普通节点和复合节点共用）
- **Composite/Pipeline/DAG Status** 专属标签页（复合节点）
- **Node Info** 面板显示节点名称、类型、子节点数、路径
- **Node Control** 启动/停止控制
- **Quick Actions** 打开文件夹、终端、IDE

### 国际化支持

为节点详情面板添加完整的国际化支持：
- 新增翻译键：`k_node_config`, `k_node_output`, `k_node_logs`, `k_composite`, `k_pipeline`, `k_dag_status` 等
- 更新 `strings_cn.json` 和 `strings_en.json`

### 防错保护

- 启动/停止按钮添加 `_operation_in_progress` 防并发标志
- 启动节点时点击停止按钮会被忽略，防止信号冲突

### 路径映射修复

统一使用 `CompositeNode` 的静态方法计算复合节点路径，确保与系统其他部分一致
