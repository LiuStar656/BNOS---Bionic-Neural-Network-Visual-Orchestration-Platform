## 五、下一步优先路线图

| 优先级 | 工作项 | 交付标准 |
|---|---|---|
| P0 | **EdgeInteractionSM → edge_item.py 接入** | edge_item.py 中 8 个旧状态变量全部删除；所有 mousePressEvent/mouseMoveEvent/mouseReleaseEvent 改为 `self._eism.handle("press_handle")` 等单事件驱动 + 单状态 `self._eism.state` 判断分支，原 8 测试继续全绿 + 新增 5+ 项接入层回归（悬停/长按/拖动/释放/leave 防呆） |
| P1 | **CanvasModeSM → canvas_view.py + tools 接入** | drawing tools 层模式切换统一走 `canvas_mode_sm.handle("enter_select"/"start_connect"/...)`，禁止裸字符串模式值流转 |
| P2 | **NodeStateActionService 挂全** | TRANSITION_TABLE 的 `action` 字段全部在 NodeStateActionService.invoke 落地，将 composite_node.py 中 expand/collapse/compress/decompress/connect/disconnect 的流程代码从老实现迁移到由 Guard + Action 驱动；原 composite_node expand/collapse 成为 NodeStateManager.handle_event(...) 的薄壳 |
| P3 | **RouteCache 一致性自测** | 加入启动自检：载入项目后 validate_all_states(node_clusters + composite + configs) 跑一轮全量，问题直接打 ERROR + GUI toast |
