# 03 日志降噪与稳态日志分级

## 问题现象

闲置状态（用户无操作）下每 3 秒一次「Canonical scan → dump 权威边集合 40+ 行」INFO 级日志，长时间运行时 bnos.log 迅速膨胀：

```
[CANONICAL] infer_all_edges done: nodes=X composites=Y ...
[RENDER-GATE] scan  canonical=Z  canvas=Z  ...
    - canonical set (len=Z):
      EdgeKey(...), EdgeKey(...), ...（Z 行）
    - canvas set (len=Z):
      EdgeKey(...), EdgeKey(...), ...（Z 行）
```

## 原因分析

1. **兜底扫描周期过短**：`CANONICAL_SCAN_INTERVAL_MS = 3000`，默认 logger 级别 INFO，每 3 秒必刷一轮 summary + dump
2. **所有集合变更都判定为 noisy**：即使是「展开折叠（集合确实该变）」也 dump，但 steady state（集合前后完全一致，0 ghost，0 broken）下 dump 对调试没用
3. **infer_all_edges summary 固定 INFO**：稳态扫描结果（成功扫描 N 节点 Y 复合节点，0 broken，0 stale）没必要 INFO 级反复打印

## 修复 1 — 拉长兜底扫描周期

```python
# 旧：CANONICAL_SCAN_INTERVAL_MS = 3_000
# 新：稳态 10s 兜底扫一次
CANONICAL_SCAN_INTERVAL_MS = 10_000
```

关键用户操作（expand / collapse / load_layout / calibrate_edges / 项目打开）都会通过 `schedule_immediate_scan()` **立即触发一次全量扫描**，不依赖定时器，10s 仅针对用户完全闲置时的兜底一致性检查，不影响正常交互反馈。

## 修复 2 — Render-Gate 日志分级

引入 `noisy` 复合判断，只有**异常或真有变化**才 INFO 级输出详细集合 dump；否则只打一行 DEBUG summary（默认 INFO logger 下 DEBUG 级不输出）：

```python
noisy = (
    bool(ghost_edges)                        # 画布有幽灵边（权威集没命中→虚线）
    or bool(stats.broken_paths)              # 配置有损坏路径
    or (pre_sizes["canonical"], pre_sizes["canvas"]) != (len(canonical_set), len(canvas_set_from_canvas))  # 集合相较上次有变化
)
# 异常/变化 → INFO 级（引起注意 + 完整 dump）
# 稳态 idle → DEBUG 级（普通运行时不刷）
summary_log = logger.info if noisy else logger.debug
set_log = logger.info if noisy else logger.debug
```

## 修复 3 — infer_all_edges summary 分级

```python
need_attention = (
    bool(stats.broken_paths)                 # 损坏配置路径
    or (stats.stale_routes_cleared or 0) > 0  # 清理了过期路由（有写操作）
)
summary_log = logger.info if need_attention else logger.debug
summary_log("[CANONICAL] infer_all_edges done: %s", stats.as_log())
```

稳态 healthy scan → DEBUG 级别，不打 INFO。

## 修复 4 — 字段名修错（ScanStats）

初版日志分级写成 `stats.stale_cleared`，但 ScanStats 定义的字段名是 `stale_routes_cleared`，运行时报：
```
AttributeError: 'ScanStats' object has no attribute 'stale_cleared'
```
已修正为 `stats.stale_routes_cleared`。

## 效果

| 场景 | 日志级别 | 输出量 |
|---|---|---|
| 闲置 steady state（无操作） | DEBUG（默认不打） | ≈ 0 |
| 用户操作 expand/collapse / 连边 | INFO | 1 轮完整 summary + dump（和旧版 3s 一轮比差 2~3 数量级） |
| 真异常（ghost 边 / broken 路径 / stale 路由） | INFO | 完整 dump，方便诊断 |
| 10s 兜底扫描 | 稳态→DEBUG，异常→INFO | 取决于状态 |
