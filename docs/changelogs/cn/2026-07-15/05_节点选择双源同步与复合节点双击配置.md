# 05 节点选择双源同步修复与复合节点双击配置页面

## 问题现象 1 — 单击切换节点后旧节点仍显示选中高亮

1. 单击画布上的 Node A，A 出现蓝色选中边框
2. 再单击画布上的 Node B，B 出现蓝色选中边框 **但 A 的蓝色边框没有消失**
3. 用户期望「普通单击 = 单选」，只有按住 Ctrl + 单击才是多选

## 根因分析 — 选中视觉依赖「双源 OR」，但清除动作只写单源

在 [node_components/rendering.py](file:///f:/Bionic%20Neural%20Network%20Program%20Operating%20System/ui/canvas/items/node_components/rendering.py#L39) 第39行，选中边框的视觉判定是：

```python
is_selected = getattr(self._node, "_is_custom_selected", False) or self._node.isSelected()
```

即两个来源**任意一个为真**就显示选中高亮：

| 来源 | 说明 | 写入方 |
|------|------|--------|
| `_is_custom_selected`（自定义标志） | 项目早期为了绕过 Qt `SingleSelection` 模式的 `NodeItem` 多选限制，添加的裸布尔标志 | `SelectionManager.on_node_selected` / `_toggle_node_selection` |
| `isSelected()`（Qt 原生 QGraphicsItem 选择状态） | `QGraphicsRectItem` 继承下来的标准选中状态，由 `QGraphicsScene.selectionChanged` / 用户框选 / `setSelected()` 写入 | Qt 场景 + 部分业务代码（框选清除、`SelectedNodesList` 写操作等） |

但是旧的 `SelectionManager.on_node_selected`（单击切换单选）只清除了 `_is_custom_selected`，**没有同步清除 Qt 原生的 `setSelected(False)`**：

```python
# ❌ 旧代码：只清自定义标志，Qt 原生 scene.selectedItems() 里 A 仍然是 True
for n in self.canvas.nodes.values():
    if getattr(n, "_is_custom_selected", False):
        n._is_custom_selected = False  # 只清了这一个
        n.update()
# 渲染层：False OR True == True → A 仍然显示选中高亮！
```

同样的问题存在于整个选择系统的**5 处写入入口**中：
1. `SelectionManager.on_node_selected`（普通单击单选）
2. `SelectionManager._toggle_node_selection`（Ctrl+单击切换多选）
3. `SelectedNodesList.append / remove / clear`（选中列表写操作 API）
4. `CanvasBoxSelect.clear_box_selection`（框选结束清除状态）

其中 1、3、4 都是「清除所有旧选择」的语义，结果只清除了双源中的一个，残留视觉。

## 修复方案 — 全链路双写双清

原则：**任何写 `_is_custom_selected` 的地方必须同时调用 `setSelected()`，两者永远保持一致。**

### 修复 1 — SelectionManager 单选入口（canvas_selection.py `on_node_selected`）

```python
# ✅ 新代码：遍历判定 OR 两边，清除时双写，末尾再加 scene.clearSelection() 兜底
for n in self.canvas.nodes.values():
    if getattr(n, "_is_custom_selected", False) or n.isSelected():
        n._is_custom_selected = False
        n.setSelected(False)
        n.update()
self.canvas.scene.clearSelection()  # Qt 场景兜底清（框选/拖拽等外部选中）
node._is_custom_selected = True
node.setSelected(True)
node.update()
```

### 修复 2 — SelectionManager 多选切换入口（canvas_selection.py `_toggle_node_selection`）

```python
# ✅ 新代码：切换时判定双源，一致切换
if getattr(node, "_is_custom_selected", False) or node.isSelected():
    node._is_custom_selected = False
    node.setSelected(False)
else:
    node._is_custom_selected = True
    node.setSelected(True)
node.update()
```

### 修复 3 — SelectedNodesList 三个写操作 API（canvas_view.py）

```python
def append(self, name):
    node = self._canvas.nodes[name]
    node._is_custom_selected = True
    node.setSelected(True)   # ✅ 加
    node.update()

def remove(self, name):
    node = self._canvas.nodes[name]
    node._is_custom_selected = False
    node.setSelected(False)  # ✅ 加
    node.update()

def clear(self):
    self._canvas.scene.clearSelection()
    for item in self._canvas.nodes.values():
        item._is_custom_selected = False
        item.setSelected(False)  # ✅ 加（和 scene.clearSelection 冗余但保持一致性）
        item.update()
```

### 修复 4 — CanvasBoxSelect 框选清除（canvas_box_select.py `clear_box_selection`）

```python
for _node_name, node in self.canvas.nodes.items():
    node.setPen(QPen(QColor(self.canvas.node_border_color), 2))
    node._is_custom_selected = False  # ✅ 加
    node.setSelected(False)
    node.update()                     # ✅ 加：刷新渲染
```

### 修复验证

| 操作 | 旧行为 | 新行为 |
|------|--------|--------|
| 单击 A → 单击 B | A、B 都有选中框 ❌ | 仅 B 有选中框 ✅ |
| Ctrl+单击 A → Ctrl+单击 B | A、B 都有选中框 ✅ | A、B 都有选中框 ✅ |
| Ctrl+单击 A（选中）→ 再 Ctrl+单击 A | A 取消选中 ✅ | A 取消选中 ✅ |
| 框选多个 → 点击空白 | 残留框选高亮 ❌（部分路径）| 全部清除 ✅ |
| 程序调 `box_selected_nodes.clear()` | 残留 Qt 选择 ❌ | 双源全清 ✅ |

## 问题现象 2 — 复合节点双击无反应

普通节点（NodeItem）双击可以打开配置详情面板，但复合节点（CompositeNodeItem）双击没有响应。用户需要在画布上快速查看/编辑复合节点的端口、内部节点、路由等配置，目前只能通过「节点列表 → 右键 → 配置」多步操作进入。

## 根因分析

- **普通节点**：`NodeItem` 的鼠标事件链完整（`mouseDoubleClickEvent` → `expand_requested` → 打开面板）
- **复合节点**：`CompositeNodeItem` 继承自 `QGraphicsRectItem`，项目初期没有覆盖 `mouseDoubleClickEvent`（也没有 `mousePressEvent`，右键菜单都走 `EventHandlers` 画布级分发），双击时直接落到 Qt 默认空实现 → 无任何业务响应

另外需要验证配置面板对复合节点是否支持。

## 修复方案

### 步骤 A — 为 CompositeNodeItem 补齐完整鼠标事件链（composite_node_item.py）

补齐 `mousePressEvent`（顺带解决普通单击选择 / Ctrl+多选 / 右键菜单 三个功能的一致性）和 `mouseDoubleClickEvent`（新功能）：

```python
def mousePressEvent(self, event):
    if event.button() == Qt.MouseButton.RightButton:
        self.contextMenuEvent(event)    # 右键：复合节点专用上下文菜单
        event.accept()
        return
    if event.button() != Qt.MouseButton.LeftButton:
        super().mousePressEvent(event)
        return
    # 连接模式：输入锚点命中 → 完成连线
    if self.canvas and self.canvas.is_connecting:
        input_anchor = self.find_nearest_input_anchor(event.pos(), 60)
        if input_anchor:
            self.canvas.complete_connection_to_input(self, input_anchor)
            event.accept()
            return
    # Ctrl + 单击 → 多选切换
    if (event.modifiers() & Qt.KeyboardModifier.ControlModifier) and self.canvas:
        self.canvas._toggle_node_selection(self.node_name)
        event.accept()
        return
    # 普通单击 → 清除旧选择，单选当前
    if self.canvas:
        self.canvas.on_node_selected(self)
    super().mousePressEvent(event)

def mouseDoubleClickEvent(self, event):
    if event.button() != Qt.MouseButton.LeftButton:
        return super().mouseDoubleClickEvent(event)
    if not self.canvas:
        return super().mouseDoubleClickEvent(event)
    try:
        self.canvas.open_node_config(self.comp_id)   # 核心：打开配置面板
        logger.info("[%s] 双击打开复合节点配置页面", self.comp_id)
    except Exception as e:
        logger.warning("[%s] 双击打开配置失败: %s", self.comp_id, e)
    event.accept()
```

### 交互行为汇总（CompositeNodeItem）

| 操作 | 响应 |
|------|------|

| 连接模式拖拽到输入区域 | 命中输入锚点 → 完成连线到该复合节点端口 |
