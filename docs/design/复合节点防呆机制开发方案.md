## 二、各机制详细设计

### S01 — DAG 环检测

**文件**: `ui/core/composite_node.py`

**实现方式**: `get_dag()` 返回边列表后，新增 `_has_cycle(edges, node_set)` 用 BFS/DFS 检测环。

```python
def _has_cycle(self, node_set: set, edges: List[dict]) -> Optional[List[str]]:
    """检测 DAG 中是否存在环。返回环路径或 None。"""
    adj = {n: [] for n in node_set}
    degree = {n: 0 for n in node_set}
    for e in edges:
        adj[e["from"]].append(e["to"])
        degree[e["to"]] += 1

    q = [n for n in node_set if degree[n] == 0]
    visited = set()
    while q:
        n = q.pop(0)
        visited.add(n)
        for nb in adj[n]:
            degree[nb] -= 1
            if degree[nb] == 0:
                q.append(nb)

    # 未访问的节点构成环
    remaining = node_set - visited
    if remaining:
        return list(remaining)
    return None
```

**调用位置**: `compress()` 第 2 步验证之后，持久化之前。检测到环时返回错误。

### S03 — 画布加载时恢复复合节点

**文件**: `canvas_view.py` 或 `canvas_menus.py` 的 `_ensure_composite_manager`

**实现方式**: 画布加载项目时，从 `node_clusters.json` 恢复所有复合节点。

```python
# canvas_view.py — 项目加载完成后调用
def restore_composites(self):
    """从 node_clusters.json 恢复复合节点到画布。"""
    project_path = self.parent_window.current_project_path
    if not project_path:
        return

    config_path = os.path.join(project_path, "node_clusters.json")
    if not os.path.exists(config_path):
        return

    try:
        with open(config_path, 'r', encoding='utf-8') as f:
            data = json.load(f)
    except Exception:
        return

    composites = data.get("composites", {})
    if not composites:
        return

    mgr = self._ensure_composite_manager_internal(project_path)
    from ui.canvas.items.composite_node_item import CompositeNodeItem

    for comp_id, comp in composites.items():
        node_names = comp.get("nodes", [])
        pos = comp.get("canvas_position", {"x": 0, "y": 0})

        # 隐藏被压缩的原始节点
        for n in node_names:
            item = self.nodes.get(n)
            if item:
                item.setVisible(False)

        # 创建复合节点 Item
        comp_item = CompositeNodeItem(
            comp_id=comp_id,
            node_count=len(node_names),
            node_names=node_names,
            canvas=self
        )
        comp_item.setPos(pos["x"], pos["y"])
        self.scene.addItem(comp_item)
        self.nodes[comp_id] = comp_item
```

### S04 — 运行时禁止切换模式

**文件**: `ui/core/composite_node.py`

**实现方式**: `set_runtime()` 中检查是否在运行。

```python
def set_runtime(self, comp_id: str, mode: str) -> Tuple[bool, str]:
    if comp_id not in self._composites:
        return False, "复合节点不存在"
    if mode not in ("process", "inprocess"):
        return False, f"无效模式: {mode}"
    if self.is_running(comp_id):
        return False, "复合节点正在运行中，请先停止后再切换模式"
    self._composites[comp_id]["runtime"] = mode
    self.save()
    return True, f"运行时模式: {mode}"
```

**调用位置**: 菜单项和右键菜单中调用 `set_runtime` 时。

### S05 — 解耦二次确认

**文件**: `ui/canvas/items/composite_node_item.py` 和 `ui/canvas/mixins/canvas_menus.py`

**实现方式**: 弹出 QMessageBox 确认。

```python
def _decompress(self):
    from PySide6.QtWidgets import QMessageBox

    reply = QMessageBox.question(
        None, "确认解耦",
        f"将复合节点还原为 {self.node_count} 个独立节点，\n确定要继续吗？",
        QMessageBox.StandardButton.Yes | QMessageBox.StandardButton.No,
        QMessageBox.StandardButton.No
    )
    if reply != QMessageBox.StandardButton.Yes:
        return

    if self._canvas and self._canvas._composite_manager:
        self._canvas._composite_manager.decompress(self.comp_id)
```

### S09 — main.py 导入失败中断

**文件**: orchestrator 模板（`_RENDER_ORCHESTRATOR`）

**修改**: `_modules` 用 None 标记导入失败的节点，`_topo_sort` 中如果 DAG 上游节点导入失败则整条链跳过。

```python
class DagRunner:
    def __init__(self):
        self._modules = {}
        self._failed = set()
        for n in NODES:
            try:
                self._modules[n["name"]] = importlib.import_module(n["module"])
            except Exception as e:
                print(f"[{comp_id}] FAIL_IMPORT {n['name']}: {e}")
                self._failed.add(n["name"])
                self._modules[n["name"]] = None

    def run(self, external_input=None):
        if self._failed:
            failed_list = ", ".join(sorted(self._failed))
            print(f"[{comp_id}] 以下节点导入失败，跳过执行: {failed_list}")
            # 不再执行，避免下游拿到空数据
            return {"code": -1, "error": f"import failed: {failed_list}"}
```

### S10 — 含孤立节点提示

**文件**: `ui/core/composite_node.py`

```python
def compress(self, node_names: List[str]) -> Tuple[bool, str, Optional[str]]:
    ...
    # 检测孤立节点（在选中范围内没有任何连线）
    if self._canvas and len(node_names) > 1:
        connected = set()
        for edge in self._canvas.edges:
            src = edge.start_node.node_name
            tgt = edge.end_node.node_name
            if src in node_set and tgt in node_set:
                connected.add(src)
                connected.add(tgt)
        isolated = set(node_names) - connected
        if isolated:
            logger.warning("以下节点在压缩集内无连线: %s", isolated)
```

### S12 — 画布外部连线保留

**当前状态**: `compress()` 隐藏原始节点但**不删除连线**。外部连线（内部↔外部）因为内部节点被 `setVisible(False)`，线还在但源/目标不可见。

**处理方式**: 压缩时，内部↔外部的连线保留在画布上（不做任何操作）。EdgeItem 绑定的是 NodeItem，NodeItem 虽然隐藏但对象仍在 `canvas.nodes` 中，连线路径更新需要处理隐藏节点的情况。如果边路径计算依赖可见性，可能需要调整。

### S14 — 复合节点位置持久化

**实现方式**: 在 CompositeNodeItem 的 `itemChange(ItemPositionHasChanged)` 中更新 `_composites` 的 `canvas_position`。或画布保存时遍历所有 CompositeNodeItem 收集位置。

```python
# composite_node_item.py
def itemChange(self, change, value):
    if change == QGraphicsItem.GraphicsItemChange.ItemPositionHasChanged:
        if self._canvas and hasattr(self._canvas, '_composite_manager'):
            mgr = self._canvas._composite_manager
            comp = mgr._composites.get(self.comp_id)
            if comp:
                comp["canvas_position"] = {"x": value.x(), "y": value.y()}
                mgr.save()
    return super().itemChange(change, value)
```
