## 二、各机制详细设计

### F01 — 删除节点时自动停止进程

**文件**: `canvas_node_manager.py`

**改动**: `remove_node_with_cleanup` 在确认后先停止进程再删除。

```python
def remove_node_with_cleanup(self, node_name):
    if node_name not in self.canvas.nodes:
        return

    # 检查运行状态并警告
    node_status = ""
    if self.canvas.parent_window and node_name in self.canvas.parent_window.nodes_data:
        node_status = self.canvas.parent_window.nodes_data[node_name].get("status", "")

    confirm_msg = t("_k_canvas_remove_node_confirm").format(name=node_name)
    if node_status in ("running", "idle"):
        confirm_msg = (
            f"节点 '{node_name}' 当前正在运行 (状态: {node_status})。\n"
            f"删除将同时停止该节点的进程。\n\n{confirm_msg}"
        )

    reply = themed_message(self.canvas, t("k_title_confirm_delete"), confirm_msg, "question")
    if not reply:
        return

    # 先停止进程
    if node_status in ("running", "idle"):
        self._stop_node_process(node_name)

    self.canvas.selection._record_delete_node(node_name)
```
