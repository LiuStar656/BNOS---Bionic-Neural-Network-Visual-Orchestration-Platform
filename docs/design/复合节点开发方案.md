# 复合节点（Composite Node）开发方案

> **BNOS 客户端层实现**。用户在画布上多选节点 → 右键"压缩为复合节点"→ 成一个节点，内部单进程运行。
> 右键复合节点 → "解耦为独立节点"→ 还原。零侵入节点代码。

---

## 一、核心概念

```
【画布操作】

  多选 3 个节点              右键 → 压缩为复合节点           画布上变成一个节点
  ┌──────┐                  ┌─────────────────┐
  │ node1 ├──┐              │  ┌───────────┐  │
  └──────┘  │   压缩        │  │ 复合节点   │  │    右键 → 解耦为独立节点
            ├──▶────────→  │  │ (3 nodes) │  │  ──────────────→  还原 3 个独立节点
  ┌──────┐  │              │  └───────────┘  │
  │ node2 ├──┤              └─────────────────┘
  └──────┘  │
            │              运行时: 单进程
  ┌──────┐  │              import 全部 main.py
  │ node3 ├──┘              → 拓扑序执行
  └──────┘                 → 写各节点 output.json
```

| 操作 | 触发方式 | 效果 |
|------|----------|------|
| 压缩 | 多选节点 → 右键"压缩为复合节点" | 画布上替换为 1 个复合节点，内部单进程运行 |
| 解耦 | 右键复合节点 → "解耦为独立节点" | 还原为原始独立节点，各走各的进程 |
| 切换模式 | 复合节点属性面板 | process / inprocess 切换 |

---

## 二、复合节点 vs 原始节点

| | 原始节点 | 复合节点 |
|------|----------|----------|
| 画布外观 | 单个节点框 | 复合节点框（带标记，如虚线边框/特殊颜色） |
| 内部结构 | 1 个 `main.py` | N 个 `main.py`，DAG 从原连线推导 |
| 运行时 | 1 个子进程 | 1 个子进程（import N 个 main.py） |
| 输出 | 1 个 `output.json` | N 个 `output.json`（各自写入） |
| 可解耦 | — | 是，右键还原 |

## 四、composite_node.py（核心逻辑）

```python
"""
ui/core/composite_node.py
复合节点管理 — 压缩/解耦/运行时切换。
"""

import os, json, importlib
from typing import Dict, List, Tuple, Optional


# ── 与 NodeGroupManager 的绑定规则 ──
# 复合节点组命名: __composite__{comp_id}
# 颜色: #4ec9b0（青绿色，匹配复合节点边框）
# 自动锁定: 压缩后 lock_group，防止用户手动移出节点
# 解耦时: unlock_group → delete_group
# 用户手动创建的节点组（无 __composite__ 前缀）不受影响

GROUP_PREFIX = "__composite__"
GROUP_COLOR = "#4ec9b0"


class CompositeNode:
    """
    复合节点：将多个原始节点包装为单个运行时单元。
    自动与 NodeGroupManager 联动：压缩 → 创建节点组，解耦 → 删除节点组。
    
    存储格式 (node_clusters.json):
    {
      "composite_1": {
        "nodes": ["node_python_prompt", "node_python_llm", "node_python_json_parser"],
        "runtime": "inprocess",
        "group_name": "__composite__composite_1",   # 关联的节点组名
        "canvas_position": {"x": 100, "y": 200},
        "original_positions": {
          "node_python_prompt": {"x": 100, "y": 200},
          ...
        }
      }
    }
    """

    def __init__(self, project_path: str, canvas=None, group_manager=None):
        self._project_path = project_path
        self._canvas = canvas
        self._group_manager = group_manager  # NodeGroupManager 实例
        self._composites: Dict[str, dict] = {}
        self._config_path = os.path.join(project_path, "node_clusters.json")
        self.load()

    # ── 持久化 ──

    def load(self):
        if os.path.exists(self._config_path):
            with open(self._config_path, 'r', encoding='utf-8') as f:
                self._composites = json.load(f).get("composites", {})

    def save(self):
        data = {"composites": self._composites}
        with open(self._config_path, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    # ── 核心操作 ──

    def compress(self, node_names: List[str]) -> Tuple[bool, str, Optional[str]]:
        """
        将多个节点压缩为复合节点。
        
        返回: (成功, 消息, 复合节点ID)
        
        步骤:
          1. 验证所有节点存在且未属于其他复合节点
          2. 保存原始画布位置
          3. 生成复合节点 ID 和对应节点组名
          4. ★ 在 NodeGroupManager 中创建同名节点组（自动锁定，防用户手动移出）
          5. 持久化
          6. 隐藏画布原始节点，显示复合节点
        """
        if not self._canvas:
            return False, "画布不可用", None

        # 1. 验证
        for n in node_names:
            existing = self._find_composite_of_node(n)
            if existing:
                return False, f"节点 '{n}' 已属于复合节点 '{existing}'", None

        # 2. 保存原始画布位置
        original_positions = {}
        for n in node_names:
            item = self._canvas._node_items.get(n)
            if item:
                original_positions[n] = {"x": item.pos().x(), "y": item.pos().y()}

        # 3. 生成 ID 和组名
        import uuid
        comp_id = f"composite_{uuid.uuid4().hex[:8]}"
        group_name = f"{GROUP_PREFIX}{comp_id}"

        # 4. ★ 在 NodeGroupManager 中创建同名节点组
        if self._group_manager:
            # 先移除节点原有的组归属（如果用户之前手动分了组）
            self._detach_from_user_groups(node_names)
            # 创建复合节点专用组
            self._group_manager.create_group(group_name, color=GROUP_COLOR)
            self._group_manager.add_nodes_to_group(group_name, node_names)
            self._group_manager.lock_group(group_name)  # 锁定，防止用户手动移出

        # 5. 计算中心位置
        if original_positions:
            cx = sum(p["x"] for p in original_positions.values()) / len(original_positions)
            cy = sum(p["y"] for p in original_positions.values()) / len(original_positions)
        else:
            cx, cy = 0, 0

        # 6. 存储
        self._composites[comp_id] = {
            "nodes": node_names,
            "runtime": "inprocess",
            "group_name": group_name,
            "canvas_position": {"x": cx, "y": cy},
            "original_positions": original_positions,
        }
        self.save()

        # 7. 画布操作: 隐藏原始节点，创建复合节点
        self._canvas_compress(comp_id, node_names, cx, cy)

        return True, f"已压缩 {len(node_names)} 个节点为复合节点", comp_id

    def decompress(self, comp_id: str) -> Tuple[bool, str]:
        """
        解耦复合节点为独立节点。
        
        步骤:
          1. 停止复合节点（如果在运行）
          2. 从画布移除复合节点，显示原始节点，还原位置
          3. ★ 删除 NodeGroupManager 中的同名节点组
          4. 清除持久化
        """
        comp = self._composites.get(comp_id)
        if not comp:
            return False, f"复合节点 '{comp_id}' 不存在"

        node_names = comp["nodes"]
        original_positions = comp.get("original_positions", {})
        group_name = comp.get("group_name", "")

        # 停止运行中的复合节点
        self._stop_if_running(comp_id)

        # 画布操作: 恢复原始节点
        self._canvas_decompress(comp_id, node_names, original_positions)

        # ★ 删除节点组（如果组存在且是复合节点组）
        if group_name and self._group_manager:
            try:
                self._group_manager.unlock_group(group_name)
            except Exception:
                pass
            try:
                self._group_manager.delete_group(group_name)
            except Exception:
                pass

        # 清除
        del self._composites[comp_id]
        self.save()

        return True, f"已解耦 {len(node_names)} 个节点"

    def set_runtime(self, comp_id: str, mode: str) -> Tuple[bool, str]:
        """切换运行时模式。"""
        if comp_id not in self._composites:
            return False, "复合节点不存在"
        if mode not in ("process", "inprocess"):
            return False, f"无效模式: {mode}"
        self._composites[comp_id]["runtime"] = mode
        self.save()
        return True, f"运行时模式: {mode}"

    def get_runtime(self, comp_id: str) -> Optional[str]:
        c = self._composites.get(comp_id)
        return c.get("runtime") if c else None

    def get_nodes(self, comp_id: str) -> List[str]:
        c = self._composites.get(comp_id)
        return list(c["nodes"]) if c else []

    # ── DAG ──

    def get_dag(self, comp_id: str) -> List[dict]:
        """推导复合节点内部的 DAG（原画布连线）。"""
        node_set = set(self.get_nodes(comp_id))
        if not self._canvas:
            return []
        edges = []
        for edge_item in self._canvas.edges.values():
            src = edge_item.start_node.name if hasattr(edge_item.start_node, 'name') else ''
            tgt = edge_item.end_node.name if hasattr(edge_item.end_node, 'name') else ''
            if src in node_set and tgt in node_set:
                edges.append({
                    "from": src,
                    "to": tgt,
                    "source_port": getattr(edge_item, '_desired_source_port_name', '') or '',
                    "target_port": getattr(edge_item, '_desired_target_port_name', '') or ''
                })
        return edges

    # ── 复合节点的对外端口 ──

    def get_external_ports(self, comp_id: str) -> dict:
        """
        返回复合节点对外暴露的端口。
        
        - 内部节点连线到外部节点 → 复合节点的输出端口
        - 外部节点连线到内部节点 → 复合节点的输入端口
        """
        node_set = set(self.get_nodes(comp_id))
        if not self._canvas:
            return {"inputs": [], "outputs": []}

        inputs, outputs = [], []
        for edge_item in self._canvas.edges.values():
            src = edge_item.start_node.name if hasattr(edge_item.start_node, 'name') else ''
            tgt = edge_item.end_node.name if hasattr(edge_item.end_node, 'name') else ''
            src_in = src in node_set
            tgt_in = tgt in node_set

            if src_in and not tgt_in:
                # 内部 → 外部 = 复合节点的输出端口
                outputs.append({
                    "name": f"{src}_to_{tgt}",
                    "internal_node": src,
                    "external_node": tgt,
                    "port": getattr(edge_item, '_desired_source_port_name', '') or "output"
                })
            elif not src_in and tgt_in:
                # 外部 → 内部 = 复合节点的输入端口
                inputs.append({
                    "name": f"{src}_to_{tgt}",
                    "external_node": src,
                    "internal_node": tgt,
                    "port": getattr(edge_item, '_desired_target_port_name', '') or "input"
                })

        return {"inputs": inputs, "outputs": outputs}

    # ── Orchestrator 生成 ──

    def generate_orchestrator(self, comp_id: str) -> str:
        """生成 orchestrator.py 并返回路径。"""
        nodes = self.get_nodes(comp_id)
        dag = self.get_dag(comp_id)
        ports = self.get_external_ports(comp_id)

        node_modules = []
        for name in nodes:
            node_modules.append({
                "name": name,
                "module": f"nodes.{name}.main",
                "path": f"./nodes/{name}"
            })

        code = _RENDER_ORCHESTRATOR(
            comp_id=comp_id,
            node_modules=node_modules,
            dag=dag,
            external_ports=ports
        )
        orch_path = os.path.join(self._project_path, f"orchestrator_{comp_id}.py")
        with open(orch_path, 'w', encoding='utf-8') as f:
            f.write(code)

        self._composites[comp_id]["orchestrator_path"] = orch_path
        self.save()
        return orch_path

    # ── 辅助 ──

    def _find_composite_of_node(self, node_name: str) -> Optional[str]:
        for cid, c in self._composites.items():
            if node_name in c.get("nodes", []):
                return cid
        return None

    def _detach_from_user_groups(self, node_names: List[str]):
        """
        将节点从用户手动创建的节点组中移出。
        只操作非复合节点组（不以 __composite__ 开头的组）。
        """
        if not self._group_manager:
            return
        for n in node_names:
            current_group = self._group_manager.node_to_group.get(n, "")
            if current_group and not current_group.startswith(GROUP_PREFIX):
                # 从用户组中移除
                try:
                    self._group_manager.remove_nodes_from_group(current_group, [n])
                except Exception:
                    pass

    @staticmethod
    def is_composite_group(group_name: str) -> bool:
        """判断一个节点组是否是复合节点自动创建的组。"""
        return group_name.startswith(GROUP_PREFIX)

    def _stop_if_running(self, comp_id: str):
        """停止复合节点的运行。"""
        from ui.core.node_control_service import NodeControlService
        service = NodeControlService.instance()
        # 停止复合节点的虚拟进程
        virtual_name = f"__composite_{comp_id}"
        try:
            service.stop_node(virtual_name)
        except Exception:
            pass

    def _canvas_compress(self, comp_id: str, node_names: list, cx: float, cy: float):
        """画布操作：隐藏原始节点 → 显示复合节点。"""
        from ui.canvas.items.composite_node_item import CompositeNodeItem

        # 隐藏原始节点
        for n in node_names:
            item = self._canvas._node_items.get(n)
            if item:
                item.setVisible(False)

        # 创建复合节点
        comp_item = CompositeNodeItem(
            comp_id=comp_id,
            node_count=len(node_names),
            node_names=node_names,
            canvas=self._canvas
        )
        comp_item.setPos(cx, cy)
        self._canvas.addItem(comp_item)
        self._canvas._node_items[comp_id] = comp_item

    def _canvas_decompress(self, comp_id: str, node_names: list, positions: dict):
        """画布操作：移除复合节点 → 显示原始节点。"""
        # 移除复合节点
        comp_item = self._canvas._node_items.pop(comp_id, None)
        if comp_item:
            self._canvas.removeItem(comp_item)

        # 还原原始节点位置
        from PySide6.QtCore import QPointF
        for n in node_names:
            item = self._canvas._node_items.get(n)
            if item:
                pos = positions.get(n, {})
                item.setPos(QPointF(pos.get("x", 0), pos.get("y", 0)))
                item.setVisible(True)
```

## 五、CompositeNodeItem（画布渲染）

```python
"""
ui/canvas/items/composite_node_item.py
复合节点的画布元素。
外观：虚线边框 + 特殊颜色 + 内部节点数标记。
"""

from PySide6.QtCore import Qt, QRectF
from PySide6.QtGui import QColor, QPen, QBrush, QPainter, QFont
from PySide6.QtWidgets import QGraphicsItem, QGraphicsRectItem, QStyleOptionGraphicsItem, QWidget


class CompositeNodeItem(QGraphicsRectItem):
    """复合节点画布元素。"""

    WIDTH = 180
    HEIGHT = 80
    BORDER_COLOR = QColor("#4ec9b0")   # 青绿色边框
    FILL_COLOR = QColor("#1e3a3a")      # 深色填充
    SELECTED_BORDER = QColor("#6ee9d0")

    def __init__(self, comp_id: str, node_count: int, node_names: list,
                 canvas=None, parent=None):
        super().__init__(parent)
        self.comp_id = comp_id
        self.node_count = node_count
        self.node_names = node_names
        self._canvas = canvas

        self.setRect(0, 0, self.WIDTH, self.HEIGHT)
        self.setFlag(QGraphicsItem.GraphicsItemFlag.ItemIsSelectable, True)
        self.setFlag(QGraphicsItem.GraphicsItemFlag.ItemIsMovable, True)
        self.setFlag(QGraphicsItem.GraphicsItemFlag.ItemSendsGeometryChanges, True)

        self._pen = QPen(self.BORDER_COLOR, 2, Qt.PenStyle.DashLine)
        self._brush = QBrush(self.FILL_COLOR)
        self._font_bold = QFont("Segoe UI", 11, QFont.Weight.Bold)
        self._font_small = QFont("Segoe UI", 9)

    def paint(self, painter: QPainter, option: QStyleOptionGraphicsItem, widget: QWidget = None):
        rect = self.rect()

        # 背景
        painter.setBrush(self._brush)
        if self.isSelected():
            painter.setPen(QPen(self.SELECTED_BORDER, 2.5, Qt.PenStyle.DashLine))
        else:
            painter.setPen(self._pen)
        painter.drawRoundedRect(rect, 8, 8)

        # 图标区域（左侧）
        icon_rect = QRectF(rect.x() + 8, rect.y() + 10, 28, 28)
        painter.setPen(Qt.PenStyle.NoPen)
        painter.setBrush(QColor("#4ec9b0"))
        painter.drawRoundedRect(icon_rect, 4, 4)

        # 图标文字（☰ 或 ⊞）
        painter.setPen(QColor("#1e1e1e"))
        painter.setFont(QFont("Segoe UI", 12, QFont.Weight.Bold))
        painter.drawText(icon_rect, Qt.AlignmentFlag.AlignCenter, "⊞")

        # 名称
        name_rect = QRectF(icon_rect.right() + 8, rect.y() + 8,
                           rect.width() - icon_rect.right() - 16, 22)
        painter.setPen(QColor("#4ec9b0"))
        painter.setFont(self._font_bold)
        short_id = self.comp_id.replace("composite_", "")[:6]
        painter.drawText(name_rect, Qt.AlignmentFlag.AlignLeft | Qt.AlignmentFlag.AlignVCenter,
                         f"复合节点 {short_id}")

        # 节点数 + 运行时模式
        sub_rect = QRectF(name_rect.x(), name_rect.bottom() + 2, name_rect.width(), 20)
        painter.setPen(QColor("#888"))
        painter.setFont(self._font_small)
        painter.drawText(sub_rect, Qt.AlignmentFlag.AlignLeft,
                         f"{self.node_count} 个节点 · inprocess")

        # 底部节点名列表（缩略）
        detail_rect = QRectF(rect.x() + 8, sub_rect.bottom() + 2,
                             rect.width() - 16, 18)
        painter.setPen(QColor("#666"))
        painter.setFont(QFont("Segoe UI", 8))
        names = ", ".join(self.node_names[:3])
        if len(self.node_names) > 3:
            names += f" +{len(self.node_names) - 3}"
        painter.drawText(detail_rect, Qt.AlignmentFlag.AlignLeft, names)

    # ── 右键菜单支持 ──

    def contextMenuEvent(self, event):
        """复合节点右键菜单。"""
        from PySide6.QtWidgets import QMenu
        menu = QMenu()
        menu.setStyleSheet("QMenu { background: #2b2b2b; color: #ccc; }")

        decompress_action = menu.addAction("解耦为独立节点")
        decompress_action.triggered.connect(lambda: self._decompress())

        menu.addSeparator()

        runtime_menu = menu.addMenu("运行时模式")
        proc_action = runtime_menu.addAction("独立进程 (process)")
        inproc_action = runtime_menu.addAction("单进程 (inprocess)")
        proc_action.triggered.connect(lambda: self._set_runtime("process"))
        inproc_action.triggered.connect(lambda: self._set_runtime("inprocess"))

        menu.addSeparator()

        start_action = menu.addAction("启动复合节点")
        stop_action = menu.addAction("停止复合节点")
        start_action.triggered.connect(lambda: self._start())
        stop_action.triggered.connect(lambda: self._stop())

        menu.exec(event.screenPos())

    def _decompress(self):
        if self._canvas and self._canvas._composite_manager:
            self._canvas._composite_manager.decompress(self.comp_id)

    def _set_runtime(self, mode):
        if self._canvas and self._canvas._composite_manager:
            self._canvas._composite_manager.set_runtime(self.comp_id, mode)

    def _start(self):
        if self._canvas and self._canvas._composite_manager:
            from ui.core.node_control_service import NodeControlService
            mgr = self._canvas._composite_manager

            if mgr.get_runtime(self.comp_id) == "inprocess":
                orch_path = mgr.generate_orchestrator(self.comp_id)
                virtual_node = {
                    'name': f'__composite_{self.comp_id}',
                    'path': os.path.dirname(orch_path),
                }
                from ui.core.node_process import start_node_process
                service = NodeControlService.instance()
                service.register_node(
                    virtual_node['name'], virtual_node['path'],
                    entry_override=os.path.basename(orch_path)
                )
                start_node_process(virtual_node)
            else:
                service = NodeControlService.instance()
                for n in mgr.get_nodes(self.comp_id):
                    service.start_node(n)

    def _stop(self):
        from ui.core.node_control_service import NodeControlService
        service = NodeControlService.instance()
        service.stop_node(f"__composite_{self.comp_id}")

    def __repr__(self):
        return f"CompositeNodeItem({self.comp_id})"
```

## 六、画布右键菜单集成

        from ui.core.composite_node import CompositeNode

## 七、Orchestrator 模板

```python
def _RENDER_ORCHESTRATOR(comp_id, node_modules, dag, external_ports):
    """生成 orchestrator.py 脚本。"""
    import json as _json
    return f'''"""
自动生成的复合节点编排器 — {comp_id}
"""
import sys, os, json, importlib, traceback

PROJECT_ROOT = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, PROJECT_ROOT)

NODES = {_json.dumps(node_modules, ensure_ascii=False)}
DAG = {_json.dumps(dag, ensure_ascii=False)}

class DagRunner:
    def __init__(self):
        self._modules = {{}}
        for n in NODES:
            try:
                self._modules[n["name"]] = importlib.import_module(n["module"])
            except Exception as e:
                print(f"[{comp_id}] ERR {{n['name']}}: {{e}}")

    def run(self, external_input=None):
         import time, uuid
         self._run_id = uuid.uuid4().hex[:12]
         self._run_ts = time.strftime("%Y-%m-%d %H:%M:%S")
         ctx = {{}}
         for node_name in self._topo_sort():
             inp = self._build_input(node_name, ctx)
             if external_input and node_name == self._find_entry_node():
                 inp["data"].update(external_input)
             try:
                 out = self._modules[node_name].process(inp)
                 ctx[node_name] = out
                 self._write_output(node_name, out)
             except Exception as e:
                 print(f"[{comp_id}] ERR {{node_name}}: {{e}}")
         return ctx

    def _topo_sort(self):
        nodes = set()
        for e in DAG: nodes.add(e["from"]); nodes.add(e["to"])
        degree = {{n: 0 for n in nodes}}
        adj = {{n: [] for n in nodes}}
        for e in DAG: adj[e["from"]].append(e["to"]); degree[e["to"]] += 1
        q = [n for n in nodes if degree[n] == 0]
        result = []
        while q:
            n = q.pop(0); result.append(n)
            for nb in adj[n]:
                degree[nb] -= 1
                if degree[nb] == 0: q.append(nb)
        return result

    def _build_input(self, node_name, ctx):
        inp = {{"data": {{}}}}
        for e in DAG:
            if e["to"] == node_name:
                upstream = ctx.get(e["from"], {{}})
                port = e.get("target_port") or ""
                if port: inp["data"][port] = upstream
                else: inp["data"].update(upstream)
        return inp

    def _find_entry_node(self):
        targets = set(e["to"] for e in DAG)
        for e in DAG:
            if e["from"] not in targets:
                return e["from"]
        return DAG[0]["from"] if DAG else ""

    def _write_output(self, node_name, output):
         for n in NODES:
             if n["name"] == node_name:
                 path = os.path.join(PROJECT_ROOT, n["path"], "output.json")
                 os.makedirs(os.path.dirname(path), exist_ok=True)
                 if not isinstance(output, dict): output = {{"data": output}}
                 if "code" not in output: output["code"] = 0
                 # ★ 写入 run_id + timestamp，外部 listener 用 run_id 防重复
                 output["run_id"] = self._run_id
                 output["timestamp"] = self._run_ts
                 with open(path, "w", encoding="utf-8") as f:
                     json.dump(output, f, ensure_ascii=False, indent=2)
                 break

if __name__ == "__main__":
    pid = os.getpid()
    pid_path = os.path.join(PROJECT_ROOT, ".pid")
    with open(pid_path, "w") as f: f.write(str(pid))
    print(f"[{comp_id}] PID={{pid}} 就绪")
    runner = DagRunner()
    result = runner.run()
    print(f"[{comp_id}] 完成")
    try: os.remove(pid_path)
    except OSError: pass
'''
```

## 十三、_port_routing 端口路由机制

### 13.1 问题背景

当复合节点连接到其他节点时，旧方案直接将路由信息写入内部节点的 `config.json`（如 `listen_upper_file`）。这导致 `_identify_ports` 方法检测到非空的 `listen_upper_file` 后跳过该节点，不再将其识别为输入端口，造成复合节点的输入端口消失。

### 13.2 解决方案

将复合节点的外部连线路由信息从内部节点 `config.json` 迁移到 `node_clusters.json` 的 `_port_routing` 字段中，与节点自身配置解耦。

**存储位置**：`node_clusters.json` → `composites.{comp_id}._port_routing`

**数据结构**：

```json
{
  "composites": {
    "composite_abc123": {
      "nodes": ["node_a", "node_b"],
      "_port_routing": {
        "input": {
          "node_a_in": {
            "source_output_path": "nodes/external_source/output.json"
          }
        },
        "output": {
          "node_b_out": {
            "target_composite": null,
            "target_node": "external_target",
            "target_port": "default"
          }
        }
      }
    }
  }
}
```

### 13.3 双向同步机制

| 操作 | 方向 | 说明 |
|------|------|------|
| **创建连线**（折叠态） | → `_port_routing` | `canvas_connections._update_composite_config_edge` 三个分支均使用 `set_input_routing` / `set_output_routing` 写入 `node_clusters.json`，不再写入内部节点 `config.json` |
| **删除连线**（折叠态） | → `_port_routing` | `remove_edge` 使用 `clear_input_routing` / `clear_output_routing` 清理 |
| **展开** | `_port_routing` → `config.json` | `_sync_configs_for_expand` 双阶段：1) 扫描画布临时连线 2) 读取 `_port_routing` 补充写入内部节点 `config.json` |
| **折叠** | `config.json` → `_port_routing` | `_sync_configs_for_collapse` 双阶段：1) 从内部节点 `config.json` 读取外部连线写回 `_port_routing` 2) 清除内部节点 `config.json` 中的外部引用 |

### 13.4 Orchestrator 外部输入注入

生成的 `orchestrator_{comp_id}.py` 在启动时读取 `node_clusters.json` 中的 `_port_routing.input`：

```python
# orchestrator 生成的 __main__ 块中
clusters_path = os.path.join(PROJECT_ROOT, "node_clusters.json")
routing = clusters["composites"][comp_id]["_port_routing"]
for port_name, route in routing["input"].items():
    src_data = json.load(open(route["source_output_path"]))
    external_input[port_name] = src_data.get("data", src_data)

runner.run(external_input=external_input)
```

`runner.run()` 已有 `external_input` 参数预留，会自动注入到入口节点的 `inp["data"]` 中。

### 13.5 约束范围（节点开发者须知）

| 约束项 | 说明 |
|--------|------|
| **`main.py` 不改动** | 节点的 `process(inp)` 函数签名和行为完全不变。`main.py` 在复合模式下被 `importlib.import_module()` 直接调用，不经过 `listener.py` |
| **`config.json` 的 `listen_upper_file` 在复合节点内部节点中保持为空** | 路由信息存储在 `_port_routing` 而非内部节点 `config.json`，确保 `_identify_ports` 正确识别输入端口 |
| **`process()` 函数保持不变** | 节点开发者无需关心复合节点路由机制，`process(inp)` 接口与独立运行时完全一致 |
| **Orchestrator 自动生成** | 编排器脚本由系统自动生成，节点开发者无需编写任何编排逻辑 |

**结论：节点开发者零改动。所有路由逻辑由 `_port_routing` + orchestrator 在系统层处理。**
